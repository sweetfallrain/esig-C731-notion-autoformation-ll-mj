Cas pratique Studio Nova

Le corrigé

Voici une solution, avec la raison de chaque choix. Si la tienne est différente mais répond aux mêmes critères, elle est juste aussi : regarde surtout les explications.

1. Où ranger le matériel ?

Le matériel, ce sont des objets du même genre, décrits par les mêmes informations : c'est une base de données (leçon 4.1). On crée sous « Studio Nova » une page « Matériel », transformée en base pleine page comme « Projets » (leçon 4.5). L'espace passe à six parties : c'est encore dans la bonne fourchette (leçon 6.1).

Autre solution acceptable : ranger la base dans « Ressources ». L'important est qu'il n'existe qu'un seul endroit pour le matériel.

2. Les propriétés

Propriétés de la base Matériel
PropriétéTypePourquoi
NomTitreLe nom de l'objet.
TypeSélectionnerUn seul type par objet : Ordinateur, Photo, Son, Dessin.
ÉtatSélectionnerDisponible, Prêté, En réparation. Le type État conviendrait aussi, mais ce n'est pas un avancement.
Emprunté parPersonnePour filtrer « mes emprunts » et prévenir la personne.
Depuis leDateUne vraie date se trie et s'affiche dans un calendrier.
Retour prévuDateIndispensable pour trier les prêts et filtrer « cette semaine ».

3. La fiche de chaque objet

Le numéro de série et les accessoires ne servent ni à trier ni à filtrer : ils vont dans le contenu de la page de l'objet, sous ses propriétés (leçon 4.2). Une colonne de plus alourdirait le tableau.

4. Les vues

  • « Tout le matériel » (Table) : la vue de départ, renommée.
  • « Prêts en cours » (Table) : filtre « État est Prêté », tri « Retour prévu, Ancien → Nouveau ». C'est la demande 4 du brief.
  • « Mes emprunts » (Liste ou Table) : filtre sur « Emprunté par », avec ton nom. C'est la demande 5.

5. Les règles de prêt

Un texte qui se lit, pas une liste qui se trie : c'est une page, rangée dans « Ressources », avec un titre « type + sujet » : « Procédure - Prêt du matériel » (leçon 6.2). Un lien « @Procédure - Prêt du matériel » en haut de la base aide à la trouver.

6. L'accueil

Dans « Accès rapides », un lien « @Matériel ». En dessous, une vue liée de la base « Matériel », nommée « Retours cette semaine », avec deux filtres : « État est Prêté » et « Retour prévu : Ce(tte) semaine » (leçon 6.3). On n'y recopie rien.

7. Le partage

Hugo n'a besoin que de consulter : on partage la base « Matériel » avec lui en « Lecture seule », le niveau le plus bas qui suffit (leçon 7.2). Pas besoin de lui ouvrir tout « Studio Nova ». L'accès général reste « Uniquement les personnes invitées ».

Ce qu'il fallait retenir

  • Des éléments qui se répètent avec les mêmes informations : une base, à un seul endroit.
  • Ce qu'on trie ou filtre devient une propriété au bon type ; le reste va dans le contenu de la page.
  • Une question = une vue ; l'accueil montre une vue liée, jamais une copie.
  • On partage en dernier, le moins possible, au niveau le plus bas qui suffit.
