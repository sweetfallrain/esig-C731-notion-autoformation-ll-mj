MÉTHODE

Comprendre comment Notion est construit.

Quatre notions suffisent à comprendre n'importe quel espace Notion. Ce sont elles qui structurent la façon dont Studio Nova organise ses projets, son équipe et ses ressources.

01 · C'est quoi Notion ? 02 · Les pages 03 · Les bases de données 04 · Les vues
01

C'est quoi Notion ?

Notion réunit dans un seul espace ce qui est aujourd'hui dispersé entre plusieurs outils : écrire, organiser des listes, partager des documents. Chez Studio Nova, ça remplace les mails de suivi, les fichiers Excel isolés et les dossiers Drive sans structure claire.

02

Les pages

Une page est un espace que l'on remplit librement : texte, images, listes, ou d'autres pages imbriquées à l'intérieur. Studio Nova a par exemple une page « Projets » qui contient une sous-page par client.

03

Les bases de données

Une base de données est un ensemble d'éléments organisés en tableau, avec des propriétés communes (statut, responsable, échéance…). C'est l'outil idéal pour suivre des listes qui évoluent dans le temps, comme les projets ou les tâches de Studio Nova. Le détail de sa construction est développé ci-dessous.

04

Les vues

Une même base de données peut s'afficher sous plusieurs vues : tableau pour tout voir d'un coup, calendrier pour les échéances, liste pour une lecture rapide. Changer de vue ne duplique jamais les données.

Une base de données = un tableau structuré.

Chaque ligne de la base est un élément (une tâche, un projet), chaque colonne une propriété (statut, échéance, responsable). Les propriétés permettent de trier, filtrer et regrouper l'information sans jamais la dupliquer.
