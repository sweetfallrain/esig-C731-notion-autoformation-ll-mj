02

Les bases : pages, blocs, pas de dossiers.

Avant les détails, il faut comprendre comment Notion structure l'information : tout est organisé autour de trois règles simples.

Les éléments clés

  • 01 Une page peut contenir d'autres pages, imbriquées sans limite de profondeur.
  • 02 Notion n'a pas de dossiers : tout est une page, même ce qui ressemble à un classeur.
  • 03 Le contenu d'une page est un empilement de blocs — texte, liste, image, base de données…
✓ Une arborescence de pages remplace avantageusement des dossiers imbriqués : plus simple à réorganiser, sans jamais perdre de contenu.
03

Les types de blocs

Une page se construit bloc par bloc. Voici les familles de blocs les plus utiles pour démarrer.

📝

Blocs classiques

Le texte et la structure de base d'une page.

  • Texte
  • Page (sous-page imbriquée)
  • Titre (utile pour une table des matières)
  • Liste à puces, numérotée, à cocher ou menu déroulant
  • Citation ou encadré
🎬

Blocs médias

Pour illustrer ou enrichir une page.

  • Image
  • Vidéo
  • Lien (avec ou sans aperçu)
🔗

Blocs d'intégration

Pour connecter d'autres outils directement dans la page.

  • Google Maps
  • Figma
  • Et bien d'autres connecteurs
